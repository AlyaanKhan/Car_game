# Overlander in Jungle

A 3D off-road driving simulator that runs entirely in the browser. One HTML file, no build step, no assets folder.

**▶ Play: https://alyaankhan.github.io/Car_game/**

![status](https://img.shields.io/badge/build-none%20required-brightgreen) ![size](https://img.shields.io/badge/size-1%20file-blue)

---

## What it is

Drive a long-wheelbase expedition 4x4 — safari roof rack, snorkel, rear ladder — along a looping trail through dense tropical jungle. Mud, rock, grass, a stream crossing with a wooden bridge, fallen logs, drifting fireflies and volumetric sunbeams.

Everything you see is **generated by code at load time**. There are no `.jpg` textures, no `.glb` models and no `.mp3` files anywhere in this repository — the terrain, the vegetation, the vehicle and even the engine sound are built procedurally in the browser.

## Controls

| Key | Action |
| --- | --- |
| `W` / `↑` | Accelerate |
| `S` / `↓` | Brake / reverse |
| `A` `D` | Steer |
| `Space` | Handbrake |
| `C` | Cycle camera |
| `V` | Undercarriage camera |
| `H` | Headlights |
| `N` | Day / night |
| `K` `B` | Horn |
| `R` | Reset vehicle |
| `P` / `Esc` | Pause |
| `M` | Mute |
| Drag | Rotate camera |

Touch controls appear automatically on phones and tablets.

## Features

- **Procedural terrain** — heightfield generated from layered noise, with a closed-loop spline trail carved through it
- **Vehicle physics** — per-wheel suspension compression, live-axle articulation, body dive / squat / roll, lateral slip and rollover detection
- **Five surface types** — dirt, mud, rock, grass and water, each with its own grip, drag and acceleration
- **Day / night cycle** — a single damped blend drives the sky shader, lighting, fog, colour grade and bloom; stars and a moon fade in, sunbeams fade out, headlights arm themselves
- **Five cameras** — chase, cockpit, inspection orbit, undercarriage and front wheel
- **Procedural audio** — the engine is synthesised live with the Web Audio API and tracks RPM; so does the horn
- **Three quality presets** — Low / Medium / High, controlling pixel ratio, shadow map size, vegetation counts and draw distance

## Running it locally

The page uses ES modules, so opening the file directly with `file://` will **not** work — browsers block module loading over that protocol. Serve it over HTTP instead:

```bash
python -m http.server 8777
```

Then open <http://127.0.0.1:8777/>.

## Tech

- [three.js](https://threejs.org/) r169, loaded from a CDN via an import map
- `EffectComposer` post-processing: bloom + a custom colour-grade shader
- Custom GLSL for the sky dome, water, vegetation wind and fireflies
- Web Audio API for all sound

## Requirements

A browser with WebGL and hardware acceleration enabled. On phones or older laptops, pick **Low** on the start screen.
